{# Write controls: the cog, the buttons, the setpoint field, the drop-down. A component template does not normally reach in here — `rows.write_controls` builds all of it from the component's `actions:` and `setpoint:` config. These macros are for a component that needs an arrangement of its own. The whole write path is two Datastar expressions: data-on:click="@post('/api/write?pv=…&value=1')" fixed value data-on:click="@post('/api/write?pv=…&signal=nl2_set')" operator's value `@post` sends every signal with the request, so the second form only has to name which signal carries the value. The server answers with SSE events that patch the status line. Every control takes a `close` signal and clears it on click, so the cog panel shuts behind the press: the result lands in the status line either way, and leaving the panel open over the value it just changed hides the thing the operator pressed the button to see. #} {% import "choices.html" as choice_options with context %} {#- `&` rather than a bare `&`: this URL is built inside an HTML attribute, and the parser decodes the entity back to `&` before Datastar sees the expression. A raw ampersand happens to work in every browser, but it is invalid markup, and one that starts a real entity name would not. -#} {%- macro write_url(pv, value=none, signal=none, status=none, close=none) -%} /api/write?pv={{ pv | urlencode }} {%- if value is not none %}&value={{ value | string | urlencode }}{% endif -%} {%- if signal is not none %}&signal={{ signal | urlencode }}{% endif -%} {%- if status is not none %}&status={{ status | urlencode }}{% endif -%} {%- if close is not none %}&close={{ close | urlencode }}{% endif -%} {%- endmacro -%} {#- Where a control reports what happened: its own line, directly beneath it. Unique per component and label, because two lasers on one page offer the same buttons and a shared id would report one laser's failure under the other's button. -#} {%- macro status_id(label) -%} {{ comp.key }}-{{ label | lower | replace(' ', '-') | replace('…', '') }}-status {%- endmacro -%} {#- A single write. `variant` is kept for semantics but every variant renders identically — see `common.Action`. -#} {%- macro action_button(label, pv, value, variant='primary', close=none) -%} {%- set target = status_id(label) -%} {%- endmacro -%} {#- Cog-icon button revealing a panel of write actions.
