{# Write controls — `components/hmi/controls/` as Jinja macros. None of this is ever patched. It is rendered once with the page and then lives entirely in the browser, because it is the half of the UI the operator *interacts* with: a cog panel that is open, a half-typed setpoint, a selected waveform. An SSE patch landing here would close panels and eat keystrokes, so widgets deliberately stop at the value cell. The whole write path is two Datastar expressions: data-on:click="@post('/api/write?pv=…&value=1')" direct write data-on:click="@post('/api/write?pv=…&signal=NL2_delay')" operator value `@post` sends every signal with the request, so the second form just names which signal carries the value. The server answers with SSE events that patch the status line — that is the whole of `usePvWrite`'s lifecycle, minus the hook. Every control that writes takes a `close` signal and clears it on click, so the cog panel shuts behind the press. `usePvWrite` did this on success; doing it on press is a deliberate difference — the result lands in the status line either way, and leaving a panel open over the value it just changed hides the thing the operator pressed the button to see. #} {#- `&` rather than a bare `&`: this URL is built inside an HTML attribute, and the parser decodes the entity back to `&` before Datastar ever sees the expression. A raw ampersand happens to work in every browser, but it is invalid markup, and the one that starts a real entity name would not. -#} {%- macro write_url(pv, value=none, signal=none) -%} /api/write?pv={{ pv | urlencode }} {%- if value is not none %}&value={{ value | string | urlencode }}{% endif -%} {%- if signal is not none %}&signal={{ signal | urlencode }}{% endif -%} {%- endmacro -%} {#- A single write. `variant` is kept for semantics (a "danger" action is still a different thing from a normal one) but every variant renders identically: a control room full of green and red buttons trains operators to look at chrome instead of at readings. -#} {%- macro action_button(label, pv, value, variant='primary', close=none) -%} {%- endmacro -%} {#- Cog-icon button revealing a panel of write actions. Two modes, as in `CogToggle.tsx`: with an `inline_label` the panel expands in normal flow inside the card (so the card grows and nothing escapes the panel border); without one it is a dropdown anchored to the cog. -#} {%- macro cog(signal, aria_label, inline_label=none) -%} {{ caller() }} {%- endmacro -%} {#- Preset chips + a free-text field for anything not on the list (`PresetIntegerInput.tsx`). The presets are the values operators actually use; the field is there because the list is never complete. -#} {%- macro preset_integer_input(label, presets, pv, signal, close=none) -%} {{ label }} {% if presets %} {% for preset in presets %} {% endfor %} {% endif %} Custom {%- endmacro -%} {#- Waveform preset chooser (`WaveformSelect.tsx`). The catalog is served with the page instead of fetched: it changes when the machine is reconfigured, not while an operator is looking at it. -#} {%- macro waveform_select(pv, signal, catalog, close=none) -%} {%- endmacro -%}
